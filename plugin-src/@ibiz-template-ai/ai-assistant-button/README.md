# 全局AI助手按钮

该插件基于面板按钮增强，主要用于在首页展示ai助手按钮。**该插件隶属于自定义部件绘制插件（基于面板按钮进行扩展）**


## 功能说明

### 插件参数

| 属性           | 类型           | 默认值                                          | 说明                                        |
| -------------- | -------------- | ---------------------------------------------- | ------------------------------------------ |
| customizedalign  | `'LEFTSTART' \| 'LEFT' \| 'LEFTEND' \| 'RIGHT' \| 'RIGHTSTART' \| 'RIGHTEND'` | 'RIGHTEND'    | 控制ai助手在屏幕中的显示位置。该参数可选值包括LEFTSTART(左上)、LEFT(左侧居中)、LEFTEND(左下)、RIGHTSTART(右上)、RIGHT(右侧居中)、RIGHTEND(右下) |
