# 动态表格列

该插件基于表格列扩展，可根据行数据动态显示单元格内容。**该插件隶属于表格列自定义绘制插件（基于表格列进行扩展）**


## 页面展示

![image](./public/assets/images/scene.png)


## 功能说明

使用该插件必须配置表格列自定义参数，用于指定需要动态显示的列和数据条件属性：

- 插件初始化时会根据 **condField（数据条件属性）** 的值判断是否显示动态列
- 数据条件判断通过后会根据 **dynamicColumn（动态列标识）**找到对应的列控制器

注意：动态列必须配置为始终隐藏模式


## 输入参数

表格列自定义参数

| 参数          | 类型   | 说明         |
| ------------- | ------ | ------------ |
| dynamicColumn | string | 动态列标识   |
| condField     | string | 数据条件属性 |
