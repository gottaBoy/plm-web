# odoo搜索栏

该插件基于搜索栏增强，主要用于以下拉框的方式呈现搜索栏过滤，分组及搜藏项，选中对应项后指定的多数据部件会根据过滤条件和分组经行数据过滤和呈现。**该插件隶属于自定义部件绘制插件（基于搜索栏部件进行扩展）**

## 功能说明

该搜索栏插件可适配任意多数据部件，因此必须在视图控制器 **state** 中声明当前激活的多数据部件名称 **xdatacontrolname**，插件通过该名称获取指定的多数据部件控制器，以便搜索栏数据变更后使指定的多数据部件经行数据过滤和分组

### 筛选

筛选数据由 **预置筛选数据** 和 **自定义筛选数据** 组成：

| 数据类型       | 数据来源                     | 是否可删除 | 是否可还原 | 是否可自定义过滤条件 |
| -------------- | ---------------------------- | ---------- | ---------- | -------------------- |
| 预置筛选数据   | 通过搜索栏过滤分组模型初始化 | 否         | 是         | 是                   |
| 自定义筛选数据 | 用户自己添加的筛选条件       | 是         | 否         | 是                   |

#### 核心逻辑

1. 可根据搜索栏配置的 **过滤组模式** 指定筛选项是否单选（默认单选），和多选时多个筛选条件之间的条件
2. 筛选数据的条件数据是根据当前搜索栏的实体**JsonSchema**计算得出，和标准搜索栏相同
3. 当预置的筛选数据变更后，配置界面会提供还原按钮，以便用户将过滤条件还原为模型配置的条件
4. 选中筛选值发生变更后会设置指定多数据部件的搜索栏参数（**searchParams**）并调用多数据部件加载（**load**）

### 分组

分组数据由 **预置分组数据** 和 **自定义分组数据** 组成：

| 数据类型       | 数据来源                             | 是否可删除 |
| -------------- | ------------------------------------ | ---------- |
| 预置分组数据   | 通过控件动态参数**DEFAULTGROUP**指定 | 否         |
| 自定义分组数据 | 用户自己添加的分组                   | 是         |

**注意：** DEFAULTGROUP 格式为: field1,field2,field3.....（多个属性之间用 , 分隔）

#### 核心逻辑

1. 解析控件动态参数**DEFAULTGROUP**，并根据实体**JsonSchema**计算出预置的分组属性
2. 分组对时间类型属性有特殊处理，可将时间按照【年，季度，月，周，天】来格式化
3. 新建分组属性时默认选中该分组
4. 选中分组时调用多数据部件执行分组（**execGroup**）

### 收藏夹

用于保存当前选中的筛选和分组数据，保存时标题默认是当前视图标题

#### 核心逻辑

1. 保存成功后会将当前选中筛选和选中分组保存到收藏中，取消筛选和分组的选中，并默认选中该收藏
2. 选中收藏时，根据收藏中的筛选和分组数据执行搜索和分组功能

### 数据存储

搜索栏用户数据通过 config 服务经行存储，每个用户都是独立的

## 参数输入

| 参数名称     | 建模             | 默认值 | 格式                      | 说明                                              |
| ------------ | ---------------- | ------ | ------------------------- | ------------------------------------------------- |
| DEFAULTGROUP | 部件控件动态参数 | -      | field1,field2,field3..... | 指定搜索栏预置分组的属性，多个属性之间使用 , 分隔 |

### 互斥项

可通过在过滤分组上配置用于参数**exclusive** 指定该项所属的互斥项组别，在同一组中的过滤项条件仅有一个可以选中

### OR条件组

可通过在过滤分组上配置用于参数**filterorgroup** 指定该项所属的OR条件组组别，在同一组中的过滤项条件单独用 OR 判断
