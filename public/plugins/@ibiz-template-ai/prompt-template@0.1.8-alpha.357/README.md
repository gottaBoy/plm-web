# 调度表格

该插件基于多行文本输入框增强，主要用于AI参数编辑，通过代码表获取指定的AI参数列表。**该插件隶属于自定义编辑器绘制插件（基于多行文本输入框进行扩展）**

## 功能说明

### 编辑器参数

| 参数标识         | 参数名称     | 说明                                                                                                                                                   |
| ---------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| appCodeListId      | 代码表标识     | 指定AI参数的列表 |
